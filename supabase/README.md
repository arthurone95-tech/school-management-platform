# Database migrations

This directory holds the version-controlled database schema for the school
management platform. Migrations here are the source of truth for the schema
(`docs/DATABASE_DOCUMENTATION.md` 8).

## Status

**Nothing in this directory has been applied to any database.** No Supabase
project exists yet (see `docs/PHASE0_RISK_REGISTER.md` section 5). The first
migration is authored and verified locally against a WASM PostgreSQL (section
10.3 of the risk register), but applying it to a real project is a separate,
authorised step.

## Layout

```
supabase/
  migrations/
    20261011000001_enrolment_foundation.sql   # tenants, membership, classes,
                                              # learners, placements,
                                              # portal credentials, audit, RLS
```

- File names are `<UTC timestamp>_<description>.sql`, ordered lexicographically.
  Supabase applies them in that order.
- Migrations are append-only. Do not edit a migration that has been applied
  anywhere; add a new one instead.
- `supabase/config.toml` is deliberately not committed yet. It is generated by
  `supabase init` when the CLI is available; a hand-written one would drift from
  the CLI's defaults.

## Applying migrations

Once a **non-production** Supabase project is authorised:

```sh
npx supabase link --project-ref <project-ref>   # requires owner authorization
npx supabase db push                            # applies pending migrations
```

Never edit a deployed database by hand, and never push to a production project
without the approval described in `AUTOMATION_WORKFLOW.md` 4.

## Local verification

`npm test` applies `migrations/20261011000001_enrolment_foundation.sql` to a
PGlite instance and asserts the tenant-isolation and audit invariants. See
`tests/database/` and `docs/PHASE0_RISK_REGISTER.md` 10.3.

Local tests prove the policy **logic**. They do not exercise Supabase Auth,
Auth Hooks, deployed grants or the Free-plan pooler, so they do not prove that a
deployed project is configured correctly.
